# Buglist 缺陷记录

本目录保存经过仿真和多轮 review 确认的缺陷记录，按责任类别和版本划分：

```text
rtl/v2  RTL 缺陷（V2）
rtl/v3  RTL 缺陷（V3）
rm/v2   RM 或测试框架缺陷（V2）
rm/v3   RM 或测试框架缺陷（V3）
```

记录前必须阅读 [buglist 缺陷记录与分析规则](../project_management/buglist_bug_record_rule.md)。当前
分支 `mem_ut_uvm_v2` 默认使用 `v2`。每个类别和版本每周只能有一个周文件；相同现象应更新已有章节，
不得重复新建。
